# Portfolio — ASSOUMANE DJIMRAOU MAHAMADOU

Portfolio personnel moderne, responsive et hébergé sur GitHub Pages.

**En ligne :** https://assoumanedjimraou-stk.github.io/folio/

## Contenu

- Hero avec terminal animé
- Profil professionnel
- Compétences (Cybersécurité, Cloud, Dev/IA/BDD, Systèmes)
- Expérience professionnelle
- Projets académiques et personnels
- Certifications & Formation
- Langues & centres d'intérêt
- Contact

## Structure

```
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   └── img/favicon.svg
└── README.md
```

## Personnalisation

- **CV :** remplacez `assets/cv-assoumane-djimraou.pdf` par votre vrai CV.
- **Couleurs :** modifiez les variables CSS dans `assets/css/style.css` (`:root`).
- **Liens :** les liens LinkedIn/e-mail/téléphone sont dans `index.html`.

## Déploiement

Le site est déployé automatiquement via GitHub Pages (branche `main`).
